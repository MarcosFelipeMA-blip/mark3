# 5 prompts para testar hoje

Estes são 5 dos 50 prompts do kit **Salão Cheio com IA**. Use em uma IA gratuita: **ChatGPT** (chatgpt.com), **Claude** (claude.ai) ou **Gemini** (gemini.google.com).

**Como usar:** copie o prompt, troque o que está entre [colchetes] pelos seus dados e cole na IA. Leia, ajuste do seu jeito e use.

## 1. Traga de volta a cliente sumida

```
Escreva 3 versões de mensagem de WhatsApp para uma cliente chamada [nome] que fazia [serviço] no meu salão e não aparece há [2 meses]. Tom: carinhoso, sem cobrança e sem parecer robô. Lembre que sentimos falta dela e ofereça um horário nesta semana. Máximo de 4 linhas.
```

> **Desafio:** mande para 5 clientes que não vêm há mais de 2 meses. Conte quantas respondem.

## 2. Responda "quanto custa?" sem perder a cliente

```
Uma pessoa perguntou no direct do meu salão: "[quanto custa a progressiva?]". O preço é a partir de R$ [valor]. Escreva uma resposta curta que informe o preço, explique o que está incluído e quanto dura o resultado, e termine com uma pergunta que puxe o agendamento. Sem parecer vendedora insistente. Dê 2 versões.
```

## 3. Encha os horários vazios da semana

```
Meu salão tem horários livres na [terça e quarta]. Crie: 1) um post para o feed com urgência sem parecer desesperado, 2) três stories, 3) uma mensagem curta de WhatsApp para as clientes. Sugira um incentivo que não seja desconto no preço.
```

## 4. Legenda de antes e depois

```
Escreva a legenda para um antes e depois de [serviço] no meu salão em [bairro]. Estrutura: frase de impacto, o que a cliente queria, como foi o processo em linguagem simples, um cuidado em casa e chamada para agendar pelo WhatsApp. Dê 3 versões e 8 hashtags locais.
```

## 5. Bio do Instagram que agenda

```
Crie 5 opções de bio para o Instagram do meu salão [nome], em [bairro, cidade], especialista em [carro-chefe], com no máximo 150 caracteres: o que faço, para quem, onde e chamada para agendar pelo link.
```
