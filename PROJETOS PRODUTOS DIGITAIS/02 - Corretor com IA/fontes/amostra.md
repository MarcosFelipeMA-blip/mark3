# 5 prompts para testar hoje

Estes são 5 dos 50 prompts do kit **Corretor com IA**. Use em uma IA gratuita: **ChatGPT**, **Claude** ou **Gemini**.

**Como usar:** copie, troque o que está entre [colchetes] e cole. **Revise sempre:** a IA não pode inventar dados do imóvel.

## 1. "Ainda está disponível?"

```
Um lead perguntou "ainda está disponível?" sobre o imóvel [resumo: tipo, bairro, 2 destaques]. Escreva uma resposta que confirme, destaque 1 detalhe forte, faça 2 perguntas de qualificação (morar ou investir? como pretende pagar?) e convide para visitar com 2 opções de horário. Dê 3 versões.
```

> **Desafio:** use no próximo lead que chegar e compare com a sua resposta de sempre.

## 2. Descrição de anúncio que gera contato

```
Escreva a descrição de anúncio deste imóvel usando SOMENTE estes dados: [tipo, bairro, metragem, quartos, suítes, vagas, andar, sol, condomínio, IPTU, preço, diferenciais, o que tem perto]. Estrutura: abertura que faça a pessoa se imaginar morando lá, lista de características, localização, chamada para visita, meu nome e CRECI [número]. Máximo de 1.500 caracteres.
```

## 3. Lead que sumiu

```
Um lead que visitou o [imóvel] há [X dias] parou de responder. Escreva 3 mensagens diferentes para reabrir a conversa: uma com novidade, uma com pergunta simples de sim ou não e uma de encerramento educado. Sem parecer desesperado.
```

## 4. Abordagem a proprietário que anuncia sozinho

```
Escreva 3 versões de mensagem para um proprietário que anuncia o próprio [tipo de imóvel] no [bairro]. Objetivo: marcar 15 minutos de conversa. Sem criticar o anúncio. Mencione 1 benefício concreto (tenho compradores com esse perfil / faço a análise de preço sem custo). Máximo de 5 linhas.
```

## 5. Objeção "achei caro"

```
Um cliente visitou o [imóvel, preço] e disse "achei caro". Imóveis parecidos na região estão entre R$ [valor] e R$ [valor]. Escreva 3 respostas respeitosas que usem dados, perguntem "caro em relação a quê?" e mantenham a conversa aberta, sem pressionar.
```
