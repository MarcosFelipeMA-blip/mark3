# mark3

## Raptor 3 desmontável

Modelo 3D interativo do motor Raptor 3 (SpaceX) que roda no navegador: abra `index.html`.

- **Desmontar próxima** (`D`) tira as 14 peças na ordem, de fora para dentro; **Recolocar** (`R`) desfaz; **Montar tudo** (`M`) reinicia.
- Clique numa peça para ver a ficha; clique duas vezes para tirá-la ou recolocá-la.
- **Vista explodida** afasta todas as peças; **Corte** (`C`) abre o motor ao meio para ver eixos, rotores e a face do injetor.
- **Ignição** (`I`) monta o motor e faz um teste estático com chama, som e telemetria.

Feito com [three.js](https://threejs.org) carregado do jsDelivr; não há etapa de build. A geometria é estilizada e os números são aproximados, com base nos dados públicos da SpaceX.
